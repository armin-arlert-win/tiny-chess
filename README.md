# TinyChess — 4 KB Python Chess Engine

[![make.fun](https://make.fun/badge/tiny-chess-01.svg)](https://make.fun/bounty/tiny-chess-01)
[![rank](https://make.fun/badge/tiny-chess-01/armin-arlert-win/tiny-chess/rank.svg)](https://make.fun/bounty/tiny-chess-01)
[![reward](https://make.fun/badge/tiny-chess-01/armin-arlert-win/tiny-chess/reward.svg)](https://make.fun/bounty/tiny-chess-01)

A chess engine in a single 4,096-byte Python file for [make.fun's tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01): alpha-beta search with iterative deepening under a fixed node budget, quiescence on captures, MVV-LVA move ordering, and a procedural piece-square evaluation. Standard library only, deterministic — no clock, no randomness.
